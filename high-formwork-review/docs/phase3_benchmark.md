## 诚实放弃（4 条保持 UNCERTAIN）

1.12（文档确实无专家论证报告）、1.17（目录结构证据不足）、2.5（浇筑工况未写明）、2.20（组合项证据部分存在）。这些规则 Agent 查证后**没有硬编判定**，理由里带查证轨迹--正是"受控自主"的目标行为。

## 发现与后续

1. **5.1 阳性对照未通过**：模型检索方向波动（搜"钢管规格/壁厚"走向材料规范章节，未搜"钢管型号"）。Phase 4 Router 设计已预留解法：route_hint 字段可把此类规则固定给批式或本地引擎，或给 agent 的首轮检索注入规则 extraction_keywords 作为查询种子
2. **耗时线性叠加**：agent 单规则 ~48s，全量 87 条若都走 agent 需 ~70 分钟。印证 Router 分流的必要性：只有 AGENT_REQUIRED 的少数疑难规则进 agent（LLM_READY 走批式 3 分钟）
3. **强制交卷是常态**（9/10）：模型倾向查满预算再收尾，强制交卷产出质量稳定（5 条 Recovery 中 4 条来自强制交卷轮）

## 结论

> **Agent 不是替代批式，而是接批式接不了的班**：56% 的批式疑难规则被 Agent 自主查证救回，且 100% 判定可溯源；救不回的诚实进人工复核。这就是"确定性任务不 Agent 化，不确定任务才 Agent 化"的实证。
