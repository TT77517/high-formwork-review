## 三、违规与缺失问题详解

### 3.1 Module 01 — 程序合规性审查（20条）

#### ❌ 违规项

**【1.17】方案内容完整性-GB55023强制（critical）**  
- **问题：** 编制依据中引用"JGJ162-2019"（《建筑施工模板安全技术规范》），该版本号不存在。JGJ162现行有效版本为JGJ162-2016。方案编制依据表第25项标注"JGJ162-2019"为错误引用。同时，计算书第一至第五类板均引用"JGJ162-2008"（第一版），亦已过期。  
- **规范依据：** GB55023 §2.0.3要求方案编制依据应准确可靠。  
- **处置建议：** 将JGJ162-2019更正为JGJ162-2016；计算书引用的JGJ162-2008应更新为JGJ162-2016。

#### ⚠️ 缺失/不规范项

**【1.14】方案内容完整性（critical）**  
- **问题：** 方案包含工程概况、编制依据、施工计划、施工工艺技术、施工安全保证措施等五项基本内容，内容完整。但编制依据缺少GB55001-2021《工程结构通用规范》和GB55008-2021《混凝土结构通用规范》的引用（仅在计算书依据中列出，正文编制依据表中未列）。  
- **处置建议：** 在正文编制依据表中补充GB55001-2021和GB55008-2021。

**【1.15】方案附加内容（critical）**  
- **问题：** 方案含计算书及施工图（平面图、剖面图、节点大样图），基本满足要求。但部分节点大样图依赖图片链接，文字描述不够充分。  
- **处置建议：** 补充关键节点的文字说明，确保方案脱离图片仍可理解。

**【1.18】安全技术交底-GB55023强制（critical）**

### 3.2 Module 02 — 荷载取值审查（18条）

#### ❌ 违规项

**【2.4】施工人员及设备荷载标准值（critical）**  
- **问题：** 方案计算书中施工人员及设备荷载标准值Q₁k取2.5kN/m²。按GB55023表4.2.4-2，支撑脚手架施工荷载标准值应≥2.5kN/m²（一般情况），有水平泵管设置时≥4.0kN/m²。方案第881行明确提到"施工荷载计算应采用4KN/m2进行复核支架承载力"，但6个计算书中均未按4.0kN/m²复核（仅取2.5kN/m²）。  
- **规范依据：** GB55023 §4.2.4及规则2.18。  
- **处置建议：** 对有泵管布置的区域，施工荷载应按4.0kN/m²重新计算并复核。

**【2.16】可变荷载调整系数γL（major）**  
- **问题：** 方案计算书考虑风荷载组合时使用了0.9组合系数（"考虑风荷载时，可变荷载需考虑0.9组合系数"），但这0.9是荷载组合值系数ψc，并非可变荷载设计工作年限调整系数γL。按GB50068，临时结构（设计工作年限5年）可变荷载调整系数γL应取0.9，方案未明确说明此参数。  
- **处置建议：** 在计算书中明确标注γL=0.9，并区分组合值系数ψc与调整系数γL。

#### ⚠️ 缺失/不规范项

**【2.5】振捣混凝土产生的荷载标准值-水平面（major）**  
- **问题：** 计算书中面板荷载组合采用1.3×(G₁k+(G₂k+G₃k)×h)+1.5×Q₁k，未单独列出振捣荷载（2.0kN/m²）。Q₁k=2.5kN/m²可能已包含施工荷载但未明确振捣荷载。  
- **处置建议：** 在荷载说明中明确振捣混凝土荷载取值及组合方式。

**【2.7】倾倒混凝土冲击荷载标准值（major）**  
- **问题：** 计算书中Q₂k取值0.06~0.211kN/m²不等，但未说明浇筑方式（泵送/溜槽/料斗），冲击荷载取值依据不明确。  
- **处置建议：** 明确浇筑方式并按规范取值。

**【2.8】混凝土侧压力计算公式（critical）**  
- **问题：** 方案对拉螺杆加固表中给出梁侧模参数，但未提供混凝土侧压力的详细计算过程。梁侧模设计仅给出间距@600mm等参数，无侧压力计算书。  
- **处置建议：** 补充梁侧模混凝土侧压力计算书。

#### ❓ 无法判定项

**【2.9】混凝土侧压力限值（critical）**  
- **问题：** 无侧压力计算过程，无法判定是否超限。  
- **处置建议：** 补充计算后复核。

### 3.3 Module 03 — 结构计算审查（21条）

#### ❌ 违规项

**【3.17】可调托撑承载力验算（critical）**  
- **问题：** 计算书第五类板（H≥8m区域）可调托座支撑点至顶层水平杆中心线距离a=500mm（line 3502），触及GB55023 §4.0.4限值（螺杆外径≤48.3mm时a≤500mm，盘扣式a≤400mm按JGJ/T231）。方案a=500mm满足GB55023上限但超过JGJ/T231推荐的400mm。经查可调托座承载力验算N=14.549kN≤100kN满足，但a值偏大。第一类梁计算书a=500mm同样触及上限。  
- **规范依据：** GB55023 §4.0.4（a≤500mm）；JGJ/T231-2021 a≤400mm（推荐性）。  
- **处置建议：** 建议将a值控制在400mm以内，更安全。

#### ⚠️ 缺失/不规范项

**【3.18】连墙件计算（major）**  
- **问题：** 方案描述了抱柱拉结措施（水平间距6~9m、竖向间距2~3m），但未提供连墙件的受力计算。  
- **处置建议：** 补充连墙件轴向力计算和承载力验算。

**【3.8a】立杆轴力设计值计算-盘扣式（critical）**  
- **问题：** 计算书立杆轴力计算公式正确（γG=1.3, γQ=1.5），但考虑风荷载时采用0.9组合系数，未明确标注该系数性质（ψc还是γL）。  
- **处置建议：** 明确0.9系数的规范出处。

#### ❓ 无法判定项

**【3.19】地基承载力验算（critical）**  
- **问题：** 方案提到"经验算，楼板承载力满足要求"（line 763），但未提供地基承载力详细计算。计算书中有立杆支承面承载力验算（冲切+局部受压），结果满足要求。  
- **处置建议：** 补充地基承载力特征值fa和立杆底压P的对比。

#### 不适用项

**【3.8/3.9/3.10/3.11】立杆轴力/稳定性/计算长度/长细比-扣件式** — 本方案为盘扣式，不适用扣件式规则。  
**【3.15】立杆稳定性验算-碗扣式** — 本方案为盘扣式，不适用。

#### ✅ 合规关键项

- **【3.1-3.3】面板验算：** 6个计算书面板抗弯σ≤15N/mm²、挠度v≤l/400，全部满足。✅

### 3.4 Module 04 — 构造要求审查（24条）

#### ❌ 违规项

**【4.17】高宽比限值（critical）**  
- **问题：** 方案多处引用"支撑架的高宽比宜控制在3以内"（JGJ/T231-2021 §6.2.1推荐性条文），使用"宜"字。但按GB55023-2022 §4.0.6，支撑脚手架独立架体高宽比**不应**大于3.0（强制性条文，用"不应"而非"宜"）。方案在编制依据和计算书中均引用推荐性条文，未引用强制性条文。  
- **规范依据：** GB55023-2022 §4.0.6（强制，"不应"）。  
- **处置建议：** 将"宜控制在3以内"更正为"不应大于3.0"，引用GB55023 §4.0.6。

**【4.12】可调托撑螺杆外伸长度限值（critical）**  
- **问题：** 方案构造要求明确"悬臂端的高度不超过650mm，露丝不超过400mm"（line 807），此为JGJ/T231-2021构造要求。但GB55023 §4.0.4规定螺杆外伸长度≤400mm（盘扣式），方案使用650mm悬臂限值偏大。计算书第一类板a=450mm，第五类板a=500mm，虽未超GB55023的500mm上限，但超过JGJ/T231推荐的400mm。  
- **规范依据：** GB55023 §4.0.4；JGJ/T231-2021 §6.1.4。  
- **处置建议：** 构造要求中悬臂限值应区分"螺杆外伸"（≤400mm）和"悬臂端高度"（a值，≤500mm），当前表述混淆。

#### ⚠️ 缺失/不规范项

**【4.10】连墙件设置（critical）**  
- **问题：** 方案描述抱柱拉结"水平间距6~9m、竖向间距2~3m"，符合GB55023 §4.0.7要求。但方案提到"当支撑架体立柱高度超过5m时"设置连墙件，GB55023要求更严格（高宽比>3时必须设置）。  
- **处置建议：** 补充高宽比>3时的连墙件设置要求。

**【4.16】盘扣式剪刀撑设置（critical）**  
- **问题：** 方案竖向斜杆布置表引用JGJ/T231-2021，设置了不同轴力区间的斜杆间距。但最高区域（19.53m）最大轴力21.04kN，按表应"间隔2跨"，方案已按此设置，基本满足。需注意H>16m时顶层步距内应每跨布置竖向斜杆，方案未明确说明。  
- **处置建议：** 补充H>16m时顶层每跨设竖向斜杆的要求。

**【4.19】水平杆通长连续设置（critical）**  
- **问题：** 方案提到"局部需采用扣件式钢管横杆过渡"（line 659），盘扣与扣件混用区域水平杆连续性可能存在不足。  
- **处置建议：** 补充混用区域水平杆连续性保证措施。

**【4.23】模板及支架设计三要素（critical）**  
- **问题：** 方案计算书包含承载力验算和刚度验算（挠度），但整体稳固性（第三要素）的论述不够充分，仅在抗倾覆验算中部分体现。  
- **处置建议：** 补充整体稳固性分析章节。

#### ❓ 无法判定项

**【4.22】满堂支撑架搭设高度限值（major）**  
- **问题：** 最高搭设高度19.53m<30m，满足限值。但方案未说明是否需特殊论证（18m以上虽未超30m但属于超过一定规模）。

### 3.5 Module 05 — 材料要求审查（18条）

#### ❌ 违规项

**【5.4】钢管规格-盘扣式（critical）**  
- **问题：** 方案立杆规格为Φ48.3×3.2mm（B型），符合JGJ/T231-2021及JG/T503-2016规定。但方案验收内容中提到"采用Φ48×3.0"（line 1273），此为扣件式钢管规格，与盘扣式立杆不符，系笔误或混用描述。  
- **处置建议：** 统一钢管规格描述，扣件式补充钢管应为Φ48.3×3.6mm（规则5.1），盘扣式立杆为Φ48.3×3.2mm。

#### ⚠️ 缺失/不规范项

**【5.5】钢管材质-盘扣式（critical）**  
- **问题：** 方案立杆材质为Q355，符合JGJ/T231-2021要求（原Q345，新标准改为Q355）。但正文编制依据未引用JG/T503-2016《承插型盘扣式钢管支架构件》，材料标准引用不完整。  
- **处置建议：** 补充JG/T503-2016引用。

**【5.8】可调托撑螺杆直径（critical）**  
- **问题：** 方案可调顶托外径38mm、壁厚5mm，满足盘扣式≥38mm要求。但验收内容中提到"可调托撑螺杆外径为36mm"（line 1275），与前述38mm矛盾。  
- **处置建议：** 统一可调托撑螺杆直径描述，以38mm为准。

**【5.13】方木规格要求（major）**  
- **问题：** 方案木枋40×90mm，满足≥40×60mm要求。但模板拼缝处"40×90木方平放方便加固，木方不作为受力构件"（line 725），平放时有效高度仅40mm，偏小。  
- **处置建议：** 非受力木枋可平放，但应确保受力木枋竖放。

#### ❓ 无法判定项

**【5.9】可调托撑钢板厚度（critical）**  
- **问题：** 方案提到壁厚5mm，但未明确托板（钢板）厚度。  
- **处置建议：** 补充托板厚度≥5mm的说明。
