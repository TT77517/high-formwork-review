### 1.2 最严重的缺口

**🔴 JGJ231-2021 vs JGJ231-2010 — 版本差异直接影响审查规则正确性**

三个方案全部引用 JGJ231-2021，而我们之前的31条规则基于 JGJ231-2010 编写。关键参数差异：

| 参数 | JGJ231-2010 (旧) | JGJ231-2021 (新) | 影响 |
|------|-------------------|-------------------|------|
| 立杆材质 | Q345 (f=300N/mm²) | Q355 (f=300N/mm²) | 材质标注变化但强度相同 |
| 钢管外径标注 | Φ48 | Φ48.3 | 计算截面仍可取Φ48×3.0 |
| 计算长度修正系数η | 1.2 (步距1.5m) | **1.05** (步距1.5m) | 直接影响λ和稳定性 |
| 悬臂折减系数k | 0.7 | **0.6** | 直接影响计算长度 |
| 搭设高度调整系数βH | 无 | 新增（H>8m时>1） | 新增参数 |
| 顶层步距修正系数γ | 无 | 新增0.9 | 新增参数 |
| 长细比容许值 | 150 (第5.1.9条) | 需查2021版条文 | 可能变化 |
| 立杆稳定性公式 | 第5.3.3条 | 第5.3.1条(新) | 公式可能调整 |
| 高宽比限值 | 3 (第6.1.4条) | 3 (第6.2.1条) | 相同 |
| 扫地杆高度 | ≤550mm (第6.1.5条) | ≤550mm | 相同 |
| 悬臂长度 | ≤650mm (第6.1.6条) | ≤650mm | 相同 |

> **关键问题**：方案1(南瑞)计算书中 η=1.05, k=0.6, βH=1, γ=0.9 → 这是JGJ231-2021的参数。
> 如果用旧版JGJ231-2010的η=1.2/k=0.7去审查，会判定方案不满足要求——这是错误的。

## 二、规则库框架设计

### 2.1 设计原则

1. **普适性**：规则基于参数阈值而非特定方案，同一规则适用于不同方案
2. **条件适用**：规则按支架类型（盘扣/扣件/碗扣）、搭设高度（≥8m/<8m）等条件区分适用范围
3. **版本兼容**：同时支持新旧规范参数，根据方案引用版本选择对应阈值
4. **可维护性**：支持增、删、改、查（CRUD）操作

### 2.2 规则分级体系

| 等级 | 标签 | 含义 | 判定后果 |
|------|------|------|---------|
| **A-强制** | mandatory | 全文强制规范条文，违反即不合规 | 红色·不合格 |
| **B-应执行** | required | 行业标准强制性条文，应严格执行 | 橙色·需整改 |
| **C-宜执行** | recommended | 行业标准推荐性条文，宜执行 | 黄色·建议整改 |
| **D-提示** | info | 程序完整性/资料完整性检查项 | 蓝色·提示完善 |

### 2.3 规则适用类型分类

| 适用类型代码 | 说明 | 关键判断字段 |
|------------|------|------------|
| `pankou` | 盘扣式钢管支架 | support_type=pankou |
| `koujian` | 扣件式钢管支架 | support_type=koujian |
| `wankou` | 碗扣式钢管支架 | support_type=wankou |
| `universal` | 所有支架类型通用 | support_type=universal |
| `height_ge8m` | 搭设高度≥8m专项规则 | height≥8 |
| `height_lt8m` | 搭设高度<8m专项规则 | height<8 |
| `high_formwork` | 高支模专项（≥5m） | height≥5 |

### 2.5 CRUD操作设计

| 操作 | 字段变化 | 说明 |
|------|---------|------|
| **增(Create)** | 新增rule_id+status=active | 按category+severity分配ID |
| **改(Update)** | 修改内容+last_modified时间戳 | 保留历史版本 |
| **删(Delete)** | status=deprecated(软删除) | 不物理删除，保留历史 |
| **查(Read)** | 按category/severity/type过滤 | 支持组合筛选 |
