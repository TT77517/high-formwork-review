> **编制日期：** 2026-08-19

> **覆盖规范：** GB55001/GB55008(全文强制) > GB50666(推荐性国标) > JGJ130/JGJ162/JGJ/T231(推荐性行业标准)
> **详细裁决：** 见 `规范冲突优先级裁决表.md`(GB55023 vs JGJ/T231) + `规范冲突扩展裁决表_JGJ130_JGJ162.md` + `规范冲突扩展裁决表_GB55008_GB55001_GB50666.md`

## 一、优先级体系

```
A级（全文强制，不可降低）
  ├─ GB55001-2021《工程结构通用规范》 → 荷载系数/γ₀/γL/作用组合
  ├─ GB55008-2021《混凝土结构通用规范》 → 模板设计三要素
  └─ GB55023-2022《施工脚手架通用规范》 → 脚手架全部技术要求

B级（推荐性国标，应执行，不得低于A级）
  └─ GB50666-2011《混凝土结构工程施工规范》 → 模板工程实施细则

C级（推荐性行业标准，应执行，不得低于A级）
  ├─ JGJ/T231-2021《盘扣式钢管脚手架安全技术标准》 → 盘扣式专用
  ├─ JGJ130-2011《扣件式钢管脚手架安全技术规范》 → 扣件式专用
  └─ JGJ162-2016《建筑施工模板安全技术规范》 → 模板设计/构造
```
