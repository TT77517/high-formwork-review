# 三方映射表 Part 3：安全构造与稳定性参数

> **方法论**：方案事实 × 规范条款 = 审查规则
> 覆盖：支架搭设参数、立杆稳定性、高宽比、抗倾覆、剪刀撑、连墙件等

---

### 规则 S-01：支模高度

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：模板支架高度H=5.87m（梁KL14）、13.88m（板模板）；方案2：搭设高度5.4m（地下一层）、14.1m（风雨操场） |
| **出现位置** | 方案1：参数表"模板支架高度H"字段（第14/18页等）；方案2：第19-20页参数表"最大搭设高度"字段 |
| **规范条款** | 住建部37号令 / 住建部令[2018]31号 |
| **规范原文** | 超过一定规模的危险性较大的高大模板工程：搭设高度8m及以上属"超过一定规模" |
| **审查规则** | 支模高度≥8m→属超过一定规模危大工程，须专家论证；≥5m→属危大工程，须编制专项方案 |
| **检查方式** | 第一类（确定性）- 提取"搭设高度"数值 |
| **风险等级** | 高（程序合规性判定） |
| **备注** | 方案1最高13.88m、方案2最高14.1m，均超8m，须专家论证 |

### 规则 S-02：立杆间距

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：板立杆纵横向间距900×900mm（第13页等）、梁跨度方向立杆间距600mm（第78页）；方案2：立杆纵距900mm、横距900mm（第19页）、人防区600×600mm |
| **出现位置** | 方案1：参数表"立杆纵/横向间距"字段；方案2：分区参数表"立杆纵距/横距"字段 |
| **规范条款** | JGJ231-2010 第6.1.4条 |
| **规范原文** | "6.1.4 模板支架的立杆间距应通过计算确定，但最大间距不宜大于1.5m" |

| **备注** | 方案1和方案2立杆间距均≤1.5m✓ |

### 规则 S-03：步距

### 规则 S-05：立杆稳定性验算

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：fd=Nd/(φA)+Mwd/W=153.791N/mm²≤[f]=300N/mm²（第89页） |
| **出现位置** | 方案1：计算书"立杆稳定性验算"结果 |
| **规范条款** | JGJ231-2010 第5.3.3条 |
| **规范原文** | "5.3.3 立杆稳定性应按下式验算：N/(φA)≤f 或 N/(φA)+Mwd/W≤f（考虑风荷载）" |
| **审查规则** | ①立杆轴力设计值Nd/(φA)+风弯矩Mwd/W≤钢材强度设计值f；②验算公式是否正确 |
| **检查方式** | 第三类（专业计算）- 需复核Nd、φ、A、Mwd、W全部参数 |
| **风险等级** | 高（核心安全验算） |
| **备注** | 方案1参数：φ=0.386, A=424mm², f=300N/mm²(Q345), η=1.2, k=0.7 |

### 规则 S-11：水平拉杆设置

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：扫地杆距地面≤350mm（引用JGJ162扣件式标准，第20页）或≤550mm（引用JGJ231盘扣式标准，第32页）；方案2：扫地杆≤550mm（第44页） |
| **出现位置** | 方案1：构造要求多处；方案2：构造要求第44页 |

| **风险等级** | 中 |
