# 三方映射表：方案事实 ←→ 规范条款 ←→ 审查规则

> **用途**：每条审查规则 = 方案中可提取的参数事实 × 规范条款原文阈值 × 检查方式
> **方法论**：设计方案4.4节"利用施工方案反向建立检查项"——从方案提取常见参数→与规范条款对照
> **规则分级**（设计方案4.6节）：第一类=确定性规则（程序判断）| 第二类=语义判断规则（大模型）| 第三类=专业计算规则（人工复核）

---

## Part 1：材料与构造参数

### 规则 M-01：立杆钢材材质等级

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1计算书：立杆抗压强度设计值[f]=300N/mm²（对应Q345）；方案2正文：立杆采用Q345 A48×3.2 |
| **出现位置** | 方案1：计算书"立杆截面参数"表（第88页等）；方案2：第21页梁支模设计表 |
| **规范条款** | JGJ231-2010 第3.2.1条：立杆采用Q345钢；水平杆采用Q235钢；斜杆采用Q195钢 |
| **规范原文** | "3.2.1 承插型盘扣式钢管支架的立杆应采用Q345钢，水平杆应采用Q235钢，斜杆应采用Q195钢" |
| **审查规则** | 检查方案中立杆材质是否标注为Q345；若标注Q235或未标注→提示 |
| **检查方式** | 第一类（确定性）- 正则匹配"Q345"关键词 |
| **风险等级** | 中（材质降级影响承载力） |
| **备注** | 方案1用强度设计值间接表达（300N/mm²=Q345），方案2直接标注Q345 |

### 规则 M-02：钢管外径与壁厚

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：材料表标注Φ48×3.0，但计算书取Φ48×3.2截面（参数矛盾）；方案2：Φ48×2.8（主梁/柱箍）、A48×3.2（立杆） |
| **出现位置** | 方案1：材料表第11页、计算书第88页；方案2：第19-21页参数表、第51页 |
| **规范条款** | JGJ231-2010 第3.2.2条：钢管壁厚允许偏差±0.1mm；JGJ130-2011 第3.4.1条 |
| **规范原文** | "3.2.2 钢管外径允许偏差为±0.5mm，壁厚允许偏差为±0.1mm" |
| **审查规则** | ①检查方案材料表与计算书中钢管规格是否一致；②壁厚偏差是否在±0.1mm内 |
| **检查方式** | 第一类（确定性）- 正则提取Φ48×X.X，对比材料表vs计算书 |
| **风险等级** | 高（壁厚直接影响截面面积和承载力） |
| **备注** | 方案1存在材料表Φ48×3.0 vs 计算书Φ48×3.2矛盾，是典型审查发现 |

### 规则 M-03：可调托座/底座丝杆外露长度

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：可调托座伸出顶层水平杆悬臂长度450mm（第13-17页参数表）；方案2：悬臂≤650mm、丝杆外露≤400mm（第44页） |
| **出现位置** | 方案1：各构件参数表"可调托座伸出顶层水平杆的悬臂长度"字段；方案2：第44页构造要求 |
| **规范条款** | JGJ231-2010 第6.1.6条（原6.1.5） |
| **规范原文** | "可调托座伸出顶层水平杆的悬臂长度严禁超过650mm，丝杆外露长度严禁超过400mm，可调托座插入立杆长度不得少于150mm" |
| **审查规则** | ①悬臂长度≤650mm（严禁）；②丝杆外露≤400mm（严禁）；③插入立杆≥150mm |
| **检查方式** | 第一类（确定性）- 提取参数表中"悬臂长度"数值与阈值比较 |
| **风险等级** | 高（严禁项，超限直接影响立杆稳定性） |
| **备注** | 方案1悬臂450mm<650mm✓；方案2在构造要求中引用规范限值但未标注实际值 |

### 规则 M-04：可调底座丝杆外露与扫地杆高度

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：扫地杆距地面≤550mm（第32页）、底层水平杆步距缩小条件（第32页）；方案2：丝杆外露≤300mm、扫地杆≤550mm（第44页） |
| **出现位置** | 方案1：第20页"扫地杆距地面高度应小于或等于350mm"→注意此处引用350mm（JGJ162标准）；第32页"距地面≤550mm"（JGJ231） |
| **规范条款** | JGJ231-2010 第6.1.5条 |
| **规范原文** | "可调底座丝杆外露长度不宜大于300mm，作为扫地杆的最底层水平杆中心线高度离可调底座的底板高度不应大于550mm" |
| **审查规则** | ①丝杆外露≤300mm；②扫地杆离地高度≤550mm |
| **检查方式** | 第一类（确定性）- 正则提取"扫地杆"+"高度"数值 |
| **风险等级** | 高 |
| **备注** | 方案1第20页写"350mm"是引用JGJ162扣件式标准，第32页写"550mm"是引用JGJ231盘扣式标准→两处标准混用 |

### 规则 M-05：可调托座承载力

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：可调托座承载力容许值[N]=30kN（第87页、第103页计算书）；方案2：未在正文中标注具体值 |
| **出现位置** | 方案1：计算书"可调托座验算"表"可调托座承载力容许值"字段 |
| **规范条款** | JGJ231-2010 第5.3.4条；JGJ130-2011 第3.4.3条 |
| **规范原文** | JGJ231第5.3.4条：连接盘抗剪承载力Qb=40kN；JGJ130第3.4.3条：可调托撑受压承载力设计值不应小于40kN |
| **审查规则** | 可调托座承载力容许值≥40kN；若方案取值<40kN→不满足 |
| **检查方式** | 第一类（确定性）- 提取"可调托座承载力"数值与40kN比较 |
| **风险等级** | 高（方案1取30kN<40kN，不满足规范要求） |
| **备注** | 方案1取30kN是典型审查发现。但需注意：方案1引用JGJ162-2008（旧版），该版未明确40kN限值 |
