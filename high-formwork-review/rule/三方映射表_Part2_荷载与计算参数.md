# 三方映射表 Part 2：荷载与计算参数

> **方法论**：方案事实 × 规范条款 = 审查规则
> 方案1计算书内嵌于正文可直接提取，方案2计算书外挂附件需单独解析

---

### 规则 L-01：永久荷载分项系数

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：永久荷载分项系数γG=1.3（第78/94页荷载系数参数表）；方案2：正文未直接标注，但引用GB55001-2021 |
| **出现位置** | 方案1：计算书"荷载系数参数表"中"永久荷载的分项系数γG"行 |
| **规范条款** | GB55001-2021 第3.1.13条第1款（全文强制，2022年1月1日起实施） |
| **规范原文** | "3.1.13 房屋建筑结构的作用分项系数应按下列规定取值：1.永久作用，当对结构不利时，不应小于1.3，当对结构有利时，不应大于1.0" |
| **旧规范对比** | JGJ162-2016 第4.2.3条：永久荷载分项系数取1.2（不利时）；GB50009-2012 第3.2.4条：1.2 |
| **审查规则** | 永久荷载分项系数γG≥1.3（不利时）；若取1.2→不满足GB55001-2021（现行全文强制规范） |
| **检查方式** | 第一类（确定性）- 提取"分项系数γG"数值与1.3比较 |
| **风险等级** | 高（影响所有承载能力计算结果） |
| **备注** | 方案1取1.3✓符合GB55001-2021；方案1引用旧规范JGJ162-2008但系数取值正确。注意：方案编制时间早于2022年1月1日时，引用1.2不宜直接判违规（用户要求考虑编制时间因素） |

### 规则 L-02：可变荷载分项系数

|------|------|

| **备注** | 方案1取1.5✓。JGJ162-2016取1.4为旧标准，被GB55001-2021取代 |

### 规则 L-03：可变荷载调整系数（设计工作年限）

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：可变荷载调整系数γL=0.9（承载能力极限状态）、γL=1.0（正常使用极限状态）（第78/94页） |
| **出现位置** | 方案1：计算书"荷载系数参数表" |
| **规范条款** | GB55001-2021 第3.1.16条 |
| **规范原文** | "3.1.16 房屋建筑的可变荷载考虑设计工作年限的调整系数γL：设计工作年限50年→γL=1.0；设计工作年限5年→γL=0.9" |
| **审查规则** | 设计工作年限为50年时γL应取1.0；若取0.9需说明依据 |

| **风险等级** | 中 |
| **备注** | 方案1取γL=0.9，对应5年设计工作年限（临时结构），合理 |

### 规则 L-05：混凝土侧压力标准值计算

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：G4k=min{0.22γct0β1β2v^(1/2), γcH}=min{29.868, 134.88}=29.868kN/m²（第70页） |

### 规则 L-06：施工荷载标准值

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：施工荷载标准值Q1k=3kN/m²（第93页等计算书） |
| **出现位置** | 方案1：计算书"荷载设计"表"施工荷载标准值Q1k"字段 |
| **规范条款** | JGJ162-2016 第4.1.2条第1款 |
| **规范原文** | "4.1.2 施工人员及设备荷载标准值(Q1k)：当计算模板及直接支承模板的小楞时取2.0kN/m²，计算其他构件时取1.5kN/m²，但较大集中荷载按实际计算" |
| **审查规则** | Q1k取值应区分计算对象：小楞取2.0，其他取1.5；方案取3.0需说明依据 |

| **风险等级** | 中 |

### 规则 L-09：荷载组合

| 维度 | 内容 |
|------|------|
| **方案事实** | 方案1：承载能力极限状态S承=1.3×G+1.5×γL×Q，正常使用极限状态S正=G+Q（计算书各页） |
| **出现位置** | 方案1：计算书"荷载设计"表"S承"和"S正"行 |
| **规范条款** | GB55001-2021 第2.4.6条、第3.1.7条；JGJ162-2016 第4.3.1条 |
| **规范原文** | GB55001第2.4.6条："基本组合、偶然组合、地震组合、标准组合、频遇组合、准永久组合"；JGJ162第4.3.1条：承载能力极限状态S=γ0[γG×SGk+γQ×SQk] |
| **审查规则** | 承载能力极限状态用设计值（含分项系数），正常使用极限状态用标准值（不含分项系数） |
| **检查方式** | 第三类（专业计算）- 需复核荷载组合公式是否正确 |
| **风险等级** | 高 |
| **备注** | 方案1明确区分S承/S正✓；但方案1计算书中公式"1.3×(G1k+(G2k+G3k)×h)+1.5×γL×Q1k"正确体现了GB55001分项系数 |
