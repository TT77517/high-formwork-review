# 方案编写模式分析与审查规则设计建议

> 目的：观察方案是怎么编写的，能从中提取哪些事实依据，从而更好地制定审查规则。
> 结合赛题说明、设计方案（实施思路汇报docx）、完整性审查规则JSON、6本规范和2份方案样本综合分析。

---

## 一、两份方案的编写模式对比

### 1.1 章节结构

| 对比维度 | 方案1（南钢智慧中心，214页） | 方案2（徐工地块中学，87页） |
|---------|---------------------------|---------------------------|
| 章节编号方式 | 中文编号（第一章/一/1） | 阿拉伯数字（1/1.1/1.1.1） |
| 工程概况 | 表格形式（参数键值对） | 混合形式（段落+表格） |
| 编制依据 | 分类表格（法规/规范规程） | 三级分类（图纸/规范/法规） |
| 技术参数 | **构件参数表**（每类构件一张表） | **分区参数表**（按区域/构件分类） |
| 计算书 | 内嵌于正文（逐构件验算） | 外挂附件（附件2-28） |

**关键发现：** 两份方案的章节框架完全一致（都对应37号令要求的10项必备内容），但内部组织方式差异很大。这对审查规则设计意味着：
- 完整性审查应基于**章节别名+关键词模糊匹配**，不能硬编码章节标题
- 参数提取需要处理**多种表格格式**（键值对表、分类列表表、分区参数表）

### 1.2 参数表述模式

方案中的关键参数以**三种模式**出现：

| 表述模式 | 方案1示例 | 方案2示例 | 审查含义 |
|---------|---------|---------|---------|
| **正文段落叙述** | "支模架搭设高度13.88m" | "立杆管为Φ48×3.2" | 语义提取，需NLP解析 |
| **结构化参数表** | 第12页"技术参数"键值对表 | 第19页"板模板及支撑设计"分区表 | 表格解析，可程序化提取 |
| **计算书内嵌参数** | 第50页荷载参数表、第88页立杆参数表 | 附件计算书（外挂未内嵌） | 计算书参数独立提取 |

**关键发现：** 同一个参数可能在方案中出现2-3次，分散在不同章节。例如方案1中：
- Φ48×3 出现在"材料计划表"和"技术参数表"
- Φ48×3.2 出现在"立杆验算参数表"
- 300N/mm² 出现在"立杆验算"部分

→ 这正是设计方案4.5节"参数一致性检查"要解决的核心问题：**同一参数在不同位置出现矛盾**。

## 二、可从方案中提取的事实依据类型

基于两份方案的实际内容，可提取的事实依据分为以下7类：

### 2.1 工程基础事实（来源：工程概况章节）

| 事实类型 | 方案1实例 | 方案2实例 | 提取方法 |
|---------|---------|---------|---------|
| 工程名称 | 南钢智慧中心 | 徐工地块社区服务中心及规划中学项目 | 键值对表格解析/正则匹配 |
| 建筑面积 | 46569m² | 50944.95m² | 同上 |
| 结构类型 | 框架 | 钢筋混凝土框架 | 同上 |
| 层高 | 标准层4200mm | 标准层4.3m | 同上 |
| 参建单位 | 建设/设计/施工/监理/项目经理 | 同左 | 表格解析 |
| 支模高度 | 13.88m | 14.1m（风雨操场） | 正则+语义 |
| 超限梁截面 | 600×3170等 | 400×2300、650×2300等 | 表格解析 |
| 超限板厚 | — | 350mm、400mm | 表格解析 |

→ **审查规则设计启示：** 工程概况章节是提取"危大工程判定阈值"事实的来源。可自动判断：
- 搭设高度≥8m → 须专家论证
- 梁截面面积≥0.45m² → 超过一定规模
- 板厚≥350mm → 超过一定规模

### 2.2 规范引用事实（来源：编制依据章节）

| 事实类型 | 方案1实例 | 方案2实例 | 提取方法 |
|---------|---------|---------|---------|
| 规范列表 | 18部规范（表格形式） | 17部规范（表格形式） | 表格解析+正则匹配编号 |
| 规范编号 | GB50009-2012 | JGJ231-2021 | 正则匹配`[A-Z]+[0-9]+-[0-9]+` |
| 规范分类 | 法规/规范规程 | 国家/行业/法规 | 表格列标题 |

→ **审查规则设计启示：**
- **可检查规范版本时效性**：比对引用版本与现行有效版本，输出"引用旧版"提示
- **可检查关键规范是否遗漏**：如未引用GB50666-2011则提示
- **注意事项**：方案引用旧版规范可能因编制时间早于新版规范发布，审查规则应标注为"提示性建议"而非"违规"

### 2.3 技术参数事实（来源：施工工艺技术章节）

这是**事实最密集的区域**。两份方案都以结构化表格列出构件参数：

**方案1模式**——每类构件一张参数表（键值对）：
```
面板材质: 覆面木胶合板
小梁材料: 矩形木楞
柱箍材料: 钢管
支撑立柱钢管型号(mm): Ф48×3
梁跨度方向立柱间距(mm): 600
支撑架中间层水平杆最大竖向步距(mm): 1500
可调托座伸出顶层水平杆的悬臂长度(mm): 450
```

**方案2模式**——按区域分组的参数表：
```
板厚mm: 400mm
最大搭设高度m: 5.40m
立杆纵距mm: 900
立杆横距mm: 900
步距mm: 1500
次龙骨规格、间距: 40mm×90mm木枋，间距400mm
主龙骨规格、间距: Φ48×2.8mm双钢管，同立杆间距600mm
```

→ **审查规则设计启示：**
- 技术参数表是**确定性规则**的核心审查对象（设计方案4.6节第一类规则）
- 可直接提取阈值参数并与规范限值比对：立杆间距≤1.5m、步距≤1.5m、可调托撑悬臂≤650mm
- 不同方案的表格格式不同，需要**自适应表格解析**能力

### 2.4 计算书参数事实（来源：计算书章节）

方案1的计算书内嵌于正文，参数以**结构化参数表+计算过程文本**混合出现：

```
立杆钢管截面类型(mm): Ф48×3.2
立杆钢管计算截面类型(mm): Ф48×3     ← 关键：标注与计算取值不一致
钢材等级: Q345
立杆截面面积A(mm2): 424
回转半径i(mm): 15.9
抗压强度设计值[f](N/mm2): 300       ← 关键：与GB50017的305不一致
```

荷载参数：
```
结构重要性系数γ0: 1
可变荷载调整系数γL: 0.9
S承=γ0×(1.3G4k+γL×1.5Q3k)          ← 关键：永久荷载1.3、可变荷载1.5
```

→ **审查规则设计启示：**
- 计算书参数是**第三类规则（专业计算）**的核心对象
- 可检查：材料标注与计算取值一致性、荷载分项系数合规性、强度取值与规范一致性
- 计算书参数可交叉比对：正文技术参数表 vs 计算书参数表 → 参数一致性检查

### 2.5 安全措施事实（来源：安全保证措施章节）

| 事实类型 | 可提取内容 | 提取方法 |
|---------|---------|---------|
| 监测点布置 | 是否设置、间距、数量 | 语义判断（非确定性） |
| 预警值 | 沉降/位移/倾斜阈值 | 正则+数值提取 |
| 应急组织 | 组织机构、职责分工 | 章节存在性+语义判断 |
| 安全技术交底 | 是否提及、交底内容 | 语义判断 |

→ 这些属于设计方案4.6节**第二类语义判断规则**，大模型判断"是否具体""是否完整"。

### 2.6 图纸事实（来源：附图章节）

| 事实类型 | 可提取内容 | 提取方法 |
|---------|---------|---------|
| 立杆间距标注 | 平面图/节点图中的尺寸标注 | OCR/视觉模型 |
| 步距标注 | 立面图/剖面图中的尺寸标注 | OCR/视觉模型 |
| 节点连接方式 | 节点大样图中的连接构造 | 视觉模型分类 |

→ 属于设计方案2.4节**图文一致性校验**范围，优先级靠后。

### 2.7 隐含事实（需推理发现）

| 事实类型 | 方案1实例 | 推理方法 |
|---------|---------|---------|
| 材料标注与计算取值矛盾 | Φ48×3(材料表) vs Φ48×3.2(计算书) | 跨章节参数比对 |
| 承载力取值低于规范 | 可调托座30kN < 规范要求40kN | 参数提取+规范比对 |
| 规范版本过时 | JGJ162-2008（已更新为2016版） | 规范库版本比对 |
| 超限梁截面面积 | 600×3170=1.902m² > 0.45m²阈值 | 数值计算判断 |

## 三、审查规则设计建议

### 3.1 规则分级策略（对应设计方案4.6节）

| 规则类型 | 可提取事实 | 审查方式 | 规则数量建议 |
|---------|---------|---------|------------|
| **第一类：确定性规则** | 章节存在性、参数阈值、规范编号、参数一致性 | 程序/规则引擎 | 40-60条 |
| **第二类：语义判断规则** | 安全措施完整性、验收程序合理性、应急预案可操作性 | 知识检索+大模型 | 15-25条 |
| **第三类：专业计算规则** | 荷载分项系数、稳定性验算、承载力验算 | 参数提取+公式复算+人工复核 | 10-20条 |

### 3.2 规则设计核心要点

**要点1：规则要基于方案中实际可提取的事实**

不是所有规范条款都能转成审查规则。只有方案中**会出现的参数**才有审查价值。从两份方案看，高频出现且可提取的关键参数：

| 参数名 | 出现位置 | 出现频率 | 规范限值来源 |
|--------|---------|---------|------------|
| 支模高度 | 工程概况/技术参数 | 100% | ≥8m须专家论证 |
| 立杆纵距 | 技术参数表/计算书 | 100% | ≤1.5m（盘扣式） |
| 立杆横距 | 技术参数表/计算书 | 100% | ≤1.5m |
| 步距 | 技术参数表/计算书 | 100% | ≤1.5m（盘扣式） |
| 可调托撑悬臂 | 技术参数表/计算书 | 100% | ≤650mm |
| 扫地杆距地面 | 技术参数/构造要求 | 80% | ≤550mm（盘扣式） |
| 钢管规格 | 材料表/技术参数/计算书 | 100% | Φ48×3.25（盘扣式B型） |
| 钢材等级 | 计算书 | 80% | Q345（盘扣式立杆） |
| 荷载分项系数 | 计算书 | 80% | 永久≥1.3/可变≥1.5 |
| 长细比 | 计算书 | 80% | ≤150 |
| 可调托座承载力 | 计算书 | 50% | ≥40kN |

**要点2：同一参数多源比对是高价值审查规则**

设计方案4.4节提到"利用施工方案反向建立检查项"。从方案1可看到：
- 钢管规格在材料表标注Φ48×3.0，在计算书标注Φ48×3.2并按Φ48×3.0取截面
- 这种"材料标注-计算取值"矛盾是工程实践中的典型风险

→ 应设计**参数一致性规则**：提取同一参数在正文/表格/计算书/图纸中的所有出现位置，比对是否一致。

**要点3：规范引用审查应区分"违规"和"提示"**

方案引用旧版规范有两种情况：
- 方案编制时间早于新版规范发布 → **提示性建议**，不判违规
- 方案编制时间晚于新版规范发布但引用旧版 → **可能违规**，需进一步判断

→ 规则设计应：提取方案编制日期+规范发布日期+现行有效版本，综合判断。

### 3.3 规则模板建议（对应设计方案4.5节）

基于以上分析，建议规则模板包含以下关键字段：

```
规则编号: R-xxx
规则分类: 完整性/程序合规/荷载取值/材料规格/支架构造/稳定性计算/变形验算/参数一致性/安全措施
规范名称: [来源规范全称]
规范版本: [版本号]
条款编号: [条款号]
条款原文: [原文引用]
审查对象: [方案中的哪个参数/章节/表格]
方案对应章节: [章节别名列表]
检查方式: 确定性/语义判断/专业计算
判定条件: [具体的阈值/公式/逻辑]
提取路径: [参数在方案中的出现位置:工程概况/技术参数表/计算书/材料表]
风险等级: critical/major/minor
规范引用时效说明: [若涉及版本问题，标注编制时间与版本关系]
整改建议: [可执行的建议]
人工复核: 是/否
```

### 3.4 实现路径建议

基于赛题要求（语义审查、图文校验、计算校验三大Agent能力）和设计方案（7个Agent），建议分阶段实现：

**第一阶段（最小闭环，对应设计方案阶段三）：**
1. 文档解析Agent：提取章节目录+结构化表格 → 输出方案JSON
2. 完整性审查Agent：执行10条完整性规则（已有completeness_rules.json）
3. 规范语义审查Agent：提取技术参数表参数，比对确定性阈值规则

**第二阶段（参数一致性，对应阶段四）：**
4. 参数提取：从正文/表格/计算书分别提取同一参数
5. 跨章节比对：输出参数矛盾清单

**第三阶段（计算校验，对应阶段五）：**
6. 计算书参数提取：荷载分项系数、钢材强度、截面参数
7. 关键公式复算：长细比验算、稳定性验算公式复算

## 四、关键结论

1. **方案是高度结构化的文档**：章节框架固定（对应37号令），参数以表格为主，适合程序化提取
2. **参数是审查事实的核心载体**：技术参数表和计算书参数表是事实密集区，应作为审查规则的主要审查对象
3. **同一参数多源出现**是方案编写模式的核心特征，参数一致性规则是最高价值的审查规则类型
4. **规范引用版本问题**需考虑方案编制时间，不宜一刀切判违规
5. **计算书内外差异**：方案1计算书内嵌（可直接提取），方案2计算书外挂附件（需单独解析），审查系统需兼容两种模式
6. **首期20-50条规则**应优先覆盖：完整性（10条）+ 确定性参数阈值（10-20条）+ 参数一致性（5-10条）+ 规范引用（5条）
