# GB55023-2022 与 JGJ/T231-2021 条文冲突优先级裁决表

> **编制日期：** 2026-08-19
> **适用项目：** 危大工程-高支模专项方案智能审查
> **核心原则：** GB55023为全文强制性工程建设规范，JGJ/T231为推荐性行业标准。
> 当两者规定不一致时，以GB55023为准（GB55023前言明确声明）。
> JGJ/T231各项技术要求不得低于GB55023的相关技术水平。

## 一、冲突类型定义

| 类型 | 定义 | 裁决原则 |
|------|------|----------|
| **真冲突** | 同一参数，数值或措辞存在矛盾 | GB55023优先（强制性高于推荐性） |
| **互补** | 不同维度/不同测量点，可同时满足 | 两者同时适用，取严 |
| **独有** | 仅一方有规定 | 直接适用该方规定 |
| **一致** | 两方规定基本相同，无矛盾 | 均可引用，优先引GB55023 |

## 二、逐项裁决表

### 1. 高宽比

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.12 支撑脚手架独立架体高宽比**不应大于3.0**（强制） |
| **JGJ/T231** | 6.2.1 支撑架的高宽比**宜控制在3以内**（推荐）；>3时应与既有结构刚性连接或增加抗倾覆措施 |
| **冲突类型** | 🔴 真冲突（措辞强度：不应 vs 宜） |
| **裁决优先级** | GB55023优先（A级强制） |
| **审查取值** | 独立支撑架高宽比≤3.0为强制限值，超限则方案不合格。JGJ/T231的连接/抗倾覆措施作为补充要求一并审查 |

### 2. 扫地杆设置

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.5 底部立杆**应设置**纵向和横向扫地杆（强制，定性要求） |
| **JGJ/T231** | 6.2.5 最底层水平杆中心线离底板高度**不应大于550mm**（定量限值） |
| **冲突类型** | 🟢 互补（定性+定量） |
| **裁决优先级** | 两者同时适用 |
| **审查取值** | 必须设置纵横向扫地杆；且扫地杆中心线距底板≤550mm。两个条件同时检查 |

### 3. 可调托撑螺杆伸出长度

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.15 调节螺杆插入立杆≥150mm；Φ42伸出≤200mm；Φ48.3+伸出≤500mm（强制） |
| **JGJ/T231** | 6.2.4 悬臂长度≤650mm；丝杆外露≤400mm；插入≥150mm |
| **冲突类型** | 🟢 互补（不同测量维度：伸出长度 vs 悬臂长度+丝杆外露） |
| **裁决优先级** | 两者同时适用 |
| **审查取值** | 盘扣式（Φ48.3）：①插入≥150mm ②调节螺杆伸出≤500mm（GB强制） ③悬臂≤650mm ④丝杆外露≤400mm。四项同时满足 |

### 4. 剪刀撑/竖向斜杆

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.13 应设竖向和水平剪刀撑（强制）；竖向宽度6~9m，倾角45°~60° |
| **JGJ/T231** | 6.2.2 按表选型竖向斜杆布置（间隔1~3跨/每跨）；6.2.7 每4~6步距设水平剪刀撑 |
| **冲突类型** | 🟢 互补（宏观强制+具体量化实施） |
| **裁决优先级** | GB55023为底线，JGJ/T231为实施细则 |
| **审查取值** | 必须设置竖向+水平剪刀撑（GB强制）；竖向斜杆布置按JGJ/T231表6.2.2选型；水平剪刀撑每4~6步距设置。倾角45°~60° |

### 5. 立杆间距/步距

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.3 立杆间距、步距**应通过设计确定**（强制，定性） |
| **JGJ/T231** | 6.1.2 根据计算选用定长水平杆；6.1.3 步距**不应超过2m** |
| **冲突类型** | 🟢 互补 |
| **裁决优先级** | 两者同时适用 |
| **审查取值** | 间距/步距须有设计计算依据；且步距≤2m为强制上限。盘扣式常用1.5m |

### 6. 水平杆通长连续设置

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.14 水平杆应按步距沿纵横向**通长连续设置**（强制） |
| **JGJ/T231** | 无直接对应条文 |
| **冲突类型** | 🔵 GB55023独有 |
| **裁决优先级** | GB55023 |
| **审查取值** | 水平杆必须纵横向通长连续，不得断开。方案中应体现连续水平杆布置图 |

### 7. 螺杆间隙

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.16 螺杆插入立杆钢管内间隙**不应大于2.5mm**（强制） |
| **JGJ/T231** | 7.4.6 立杆外径与螺母台阶内径差**不应大于2mm** |
| **冲突类型** | 🟡 真冲突+不同测量点（2.5mm vs 2mm，相关但非同一位置） |
| **裁决优先级** | 两者同时适用，取严 |
| **审查取值** | ①螺杆-立杆内壁间隙≤2.5mm（GB强制底线） ②立杆外径-螺母台阶内径差≤2mm（JGJ/T231更严，盘扣式适用）。两个测量点分别检查 |

### 8. 施工荷载标准值

| 项目 | 内容 |
|------|------|
| **GB55023** | 表4.2.4-2 支撑脚手架：一般2.5kN/m²，有水平泵管4.0kN/m² |
| **JGJ/T231** | 4.2.3 施工人员及设备荷载不应小于2.5kN/m²（无泵管区分） |
| **冲突类型** | 🟢 互补（GB55023更细化） |

| **审查取值** | 一般≥2.5kN/m²；有水平泵管≥4.0kN/m²。JGJ/T231的2.5为最低底线，泵管场景须按GB55023取4.0 |

## 三、裁决优先级总览

| 优先级 | 规范 | 等级 | 适用规则 |
|--------|------|------|----------|
| **A（最高）** | GB55023-2022 | 全文强制性 | 直接强制执行，不可降低 |
| **B** | JGJ/T231-2021 | 推荐性行业标准 | 应执行，不得低于GB55023技术水平 |
| **C** | JGJ130-2011/JGJ162-2016等 | 推荐性 | 参考执行，与GB55023冲突时以GB55023为准 |
