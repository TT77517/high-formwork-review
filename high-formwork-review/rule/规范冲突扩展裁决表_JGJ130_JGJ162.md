# GB55023-2022 与其他规范冲突扩展裁决表

> **编制日期：** 2026-08-19
> **适用项目：** 危大工程-高支模专项方案智能审查
> **覆盖规范：** JGJ130-2011、JGJ162-2016、GB55008-2021、GB55001-2021、GB50666-2011
> **基准规范：** GB55023-2022《施工脚手架通用规范》（全文强制性）
> **核心原则：** 全文强制性规范(GB55023/GB55008/GB55001) > 推荐性国标(GB50666) > 推荐性行业标准(JGJ130/JGJ162)

## 冲突类型定义

| 类型 | 定义 | 裁决原则 |
|------|------|----------|
| **真冲突** | 同一参数，数值或措辞存在矛盾 | 强制规范优先 |
| **互补** | 不同维度/不同测量点 | 两者同时适用，取严 |
| **独有** | 仅一方有规定 | 直接适用 |
| **一致** | 两方规定基本相同 | 均可引用，优先引强制规范 |
| **过时** | 旧版规范系数已被新强制规范取代 | 以新强制规范为准 |

## A. JGJ130-2011《扣件式钢管脚手架安全技术规范》 vs GB55023

### A1. 荷载分项系数（过时）

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.3.4 采用荷载基本组合（引用GB55001） |
| **GB55001** | 3.1.13 永久作用不利≥1.3；可变作用不利≥1.5（全文强制） |
| **JGJ130** | 4.3.2 永久1.2/可变1.4（旧版系数） |
| **冲突类型** | 🔴 真冲突（过时：1.2/1.4 vs 1.3/1.5） |
| **裁决优先级** | GB55001优先（全文强制） |
| **审查取值** | γG=1.3, γQ=1.5。JGJ130旧系数1.2/1.4已被取代，方案若沿用旧系数则判为不合格 |

### A2. 施工荷载标准值（一致+互补）

| 项目 | 内容 |
|------|------|
| **GB55023** | 表4.2.4-2 支撑脚手架：一般2.5kN/m²，有泵管4.0kN/m² |
| **JGJ130** | 4.2.4 引用JGJ162取值；4.2.2 作业脚手架3.0(砌筑)/2.0(其他) |
| **冲突类型** | 🟢 互补（GB55023细化泵管场景） |
| **裁决优先级** | GB55023优先 |
| **审查取值** | 支撑架一般≥2.5，有泵管≥4.0；作业架按GB55023表4.2.4-1 |

### A3. 扫地杆距地面高度（真冲突）

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.5 应设置纵横向扫地杆（定性，未给具体高度） |
| **JGJ130** | 6.3.2 纵向扫地杆距底端**不大于200mm** |
| **JGJ162** | 6.1.9 距地面**200mm**高处设扫地杆 |

| **审查取值** | 必须设置纵横向扫地杆（GB强制）；扣件式距底端≤200mm。盘扣式按JGJ/T231≤550mm（不同体系不同限值） |

### A4. 高宽比（真冲突）

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.12 独立架体高宽比**不应大于3.0**（强制） |
| **JGJ130** | 6.9.7 高宽比大于2或2.5时须与结构刚性连接；**不应大于3** |
| **JGJ162** | 5.1.7 群柱架高宽比**不应大于5**（扣件钢管作支架立柱时） |
| **冲突类型** | 🟡 真冲突（3.0 vs 5.0，JGJ162明显放宽） |
| **裁决优先级** | GB55023优先（强制≤3.0），JGJ162的5.0已被取代 |
| **审查取值** | 独立支撑架高宽比≤3.0。JGJ162的5.0限值过宽，不得采用 |

### A5. 可调托撑螺杆伸出长度（互补+真冲突）

| 项目 | 内容 |

| **GB55023** | 4.4.15 插入≥150mm；Φ42伸出≤200mm；Φ48.3+伸出≤500mm（强制） |
| **JGJ130** | 6.9.6 螺杆伸出**不宜超过300mm**；插入≥150mm |
| **JGJ162** | 6.1.9 螺杆伸出钢管顶部**不得大于200mm**；间隙不得大于3mm |
| **冲突类型** | 🟡 真冲突（500 vs 300 vs 200，不同体系不同限值） |

| **审查取值** | 扣件式(Φ48.3)：≤300mm（JGJ130）且≤500mm（GB底线）；盘扣式：按GB55023≤500mm+JGJ/T231悬臂≤650mm+外露≤400mm。JGJ162的200mm适用木立柱/钢管混合体系 |

|------|------|

### A7. 剪刀撑设置（互补）

| 项目 | 内容 |
|------|------|
| **GB55023** | 4.4.13 应设竖向+水平剪刀撑；竖向宽度6~9m，倾角45°~60°（强制） |
| **JGJ130** | 6.9.3 普通型竖向5~8m间距/加强型4~5跨；水平剪刀撑顶部+扫地杆层+间距≤8m |
| **JGJ162** | 6.2.4 外侧周圈竖向连续剪刀撑；中间每10m设竖向；顶部+扫地杆设水平；8~20m加之字撑 |
| **冲突类型** | 🟢 互补（GB55023宏观强制+JGJ130/JGJ162具体量化） |
| **裁决优先级** | GB55023为底线，JGJ130/JGJ162为实施细则 |
| **审查取值** | 必须设置竖向+水平剪刀撑（GB强制）；竖向剪刀撑宽度6~9m、倾角45°~60°（GB）；具体间距按JGJ130普通型/加强型选型或JGJ162每10m |
